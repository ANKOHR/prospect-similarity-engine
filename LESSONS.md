# Lessons for KOML

The domain requires explicit response semantics and consistent categories. A feature match is auditable, but cannot establish purchase intent or whether a reply was positive.

The synthetic evidence validates the assumption that a deterministic four-field rule can recover planted matches exactly. The assumption that these similarities improve actual outreach remains untested; no real trial data was supplied.

Operating rule: specify and hand-compute independent fixture truth before implementing the score, then test a mutation of the input to prove outputs come from data. Keep planted correctness separate from real-world usefulness.
